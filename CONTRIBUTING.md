# Contributing

The public GitHub repository accepts bug reports and security reports through
the channels documented in `README.md` and `SECURITY.md`. External code, asset,
translation, and documentation contributions are not currently accepted.

If this policy changes, the project will define contributor licensing and
provenance requirements before accepting a pull request.

Except for material identified in `THIRD_PARTY_NOTICES.md`, the application is
licensed under `AGPL-3.0-or-later`. Contributors must only submit material they
are entitled to license under those terms. Do not copy code, assets,
translations, model files, or documentation without recording their origin and
compatible license.
